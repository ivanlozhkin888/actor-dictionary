# Сеульский словарь актёра

Приложение для изучения английских слов для актёров и моделей, которые снимаются в Южной Корее. Слова разбиты на уроки, прогресс сохраняется в браузере.

Всё приложение — один файл `index.html`, без сборки и зависимостей.

## Как открыть

- Локально: скачай `index.html` и открой в браузере.
- Как сайт: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту приложение будет доступно по адресу https://ivanlozhkin888.github.io/actor-dictionary/.
